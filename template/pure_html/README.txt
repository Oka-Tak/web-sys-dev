共有用・大きめ pure HTML 画面枠テンプレート

使い方
1. 00-template-list.htmlを開く。
2. 担当画面に近いテンプレートを選ぶ。
3. HTMLファイルを複製して、タイトルと中央部分を変更する。
4. hrefとform actionを、実際の移動先ファイル名に書き換える。

共通仕様
- 横幅: 1100
- 本文: font size 5
- サイト名: font size 7
- 内容領域の最低高さ: 600
- CSS、JavaScriptなし
- 枠、余白、背景色、文字サイズはHTML属性で指定

重要
- 1100px幅のため、スマートフォンでは横にはみ出す場合がある。
- 現代的なWeb制作ではCSSを利用するが、今回はpure HTMLの確認用。
- 検索、絞り込み、計算、保存などの処理は行わない。
